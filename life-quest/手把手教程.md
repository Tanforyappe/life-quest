# 手把手：从零做出属于你的「人生副本」

> 你已经拿到成品了（`life-quest` 文件夹）。这份教程讲两件事：
> **① 怎么让它在你 iPhone 和 Windows 上真正用起来；② 想自己改，从哪儿下手。**
>
> 全程不需要写一行"从零开始"的代码，也不需要花钱。

### 📌 v3.0 又加了 6 个系统

| 新系统 | 一句话说明 | 在哪 |
|---|---|---|
| **惩罚系统** | 自定义「做错了什么 → 扣多少经验/金币」，破戒就点「记一次」 | 奖励页 → 切到「惩罚」 |
| **娱乐时长** | 独立的一种"钱"：金币兑换（比例可自定义）+ 每日达标赠送，累积不清零；**用掉才算真的花出去** | 奖励页顶部卡片 |
| **每日记录 + 日记** | 每天自动汇总金币收支（奖励/惩罚分开算），还能写日记、选心情 | 记录页 → 「日记」 |
| **收支流水** | 经验 / 金币 / 时长每一笔增减都有记录，可按类型筛 | 记录页 → 「流水」 |
| **备忘录** | 记事 + 设提醒时间，到点在应用里弹提醒 | 底部「备忘」 |
| **数值全可调** | 专注每分钟奖励、时长兑换比例、每日达标门槛，全都能改 | 我的 → 数值设置 |

**推荐这么串起来用（一个完整闭环）：**

1. 打卡 → 赚经验 + 金币
2. 金币有两个去处：买奖励（奶茶 / 追剧），或者换**娱乐时长**（默认 2 金币换 1 分钟，比例能改成「几金币换几分钟」）
3. 想玩的时候，在时长卡片里输入分钟数点「**用掉**」—— 时长只有被用掉才算真的花出去，这样它才管得住你
4. 破戒了 → 去「惩罚」记一次，扣经验扣金币。**有奖励也有代价，这套系统才不会变成只进不出的许愿池**
5. 睡前 → 「日记」写两句，顺手看一眼今天金币花在哪儿了

> ⚠️ **关于备忘提醒**：网页应用只有在**打开时**才能响。iPhone 上彻底关掉后不会提醒（iOS 的限制，不是 bug）。
> 特别重要的事，建议同时设到系统「提醒事项」里。
>
> 老数据会自动升级，不用重来。第一次打开 v2 时，**已经解锁的成就不会补发金币**（避免一次刷一堆），之后的才发。
> v3 打开时，会用你已有的打卡记录**自动补一份收支流水**。

## 第 0 步 · 先搞清楚"做一个 App"有哪三条路

很多人一开始就卡在这里：以为做 App = 学 Swift = 买 Mac = 交 99 美元。其实不是。你这种"自己用的打卡游戏"，有三条路：

| 做法 | 长什么样 | 花钱 | 难度 | 你适合吗 |
|---|---|---|---|---|
| **网页应用（PWA）** | 浏览器打开，能"添加到主屏幕"，全屏、有图标、能离线 | 0 元 | ★ | ✅ **就是它** |
| 微信小程序 | 微信里搜索打开，扫码即用 | 0 元（要注册小程序） | ★★ | 想分享给朋友时再说 |
| 原生 App | 应用商店下载 | 每年 $99 + 必须有 Mac | ★★★★★ | 不建议 |

**为什么选网页应用：**

1. 一份代码，iPhone 和 Windows 同时能用（你花的时间只花一次）。
2. 改完刷新就生效，不用重新下载安装。
3. 加到 iPhone 桌面后，**全屏打开、没有地址栏、有自己的图标**，你妈都看不出这是网页。
4. 不用审核、不用上架、不用开发者账号。

代价只有一个：**它需要一个网址**。因为 iPhone 没法直接打开你电脑里 D 盘的文件。网址怎么来，第 3 步讲，免费。

## 第 1 步 · 认识这 3 个文件（1 分钟）

一个网页应用，本质上就是 3 个文件。拿盖房子打比方：

| 文件 | 类比 | 里面是什么 |
|---|---|---|
| `index.html` | 房子的**骨架** | 页面上有哪些区块：顶部状态栏、4 个标签页、底部导航 |
| `styles.css` | 房子的**装修** | 颜色、圆角、字号、动画 |
| `app.js` | 房子的**电路和开关** | 打卡加经验、升级、扣金币、数据存哪里 |

再加 2 个"说明书"：

- `manifest.json` → 告诉手机："我叫人生副本，图标是这个，打开时不要显示浏览器地址栏。"
- `sw.js` → 让应用**断网也能打开**（提前把文件存到手机里）。

就这些。没有数据库，没有服务器，没有账号系统。你的数据存在手机的浏览器里。

## 第 2 步 · 先在 Windows 上用起来（现在就能做）

1. 打开文件夹 `life-quest`。
2. **双击 `index.html`**。会用 Edge / Chrome 打开。
3. 先玩 5 分钟，把这 5 件事都试一遍：

   - 点「打卡」→ 看顶部经验条涨了、金币加了，还会弹出 "+15 XP"
   - 点「阅读 20 页」的「+1」三次、再点「记满」
   - 点「＋ 新建每日任务」，随便建一个
   - 切到「奖励」，去兑换一个（金币不够就先攒）
   - 切到「记录」，看热力图和成就墙
   - 切到「我的」→「导出备份」，看是不是下载了一个 .json 文件

4. 想固定入口：浏览器右上角 `⋯` → 收藏夹，或者右键 `index.html` → 发送到 → 桌面快捷方式。

> **这一步很重要**：先在电脑上把功能试熟，再去手机上装。电脑上调试最方便（按 F5 刷新就能看到改动）。

## 第 3 步 · 让它在 iPhone 上能用（关键的一步）

iPhone 需要一个**网址**才能打开它。有两条免费的路，选一条就行。

### 方案 A：Netlify Drop（5 分钟，最简单，推荐先用这个）

1. 电脑浏览器打开 <https://app.netlify.com/drop>
2. 打开另一个窗口，找到你的 `life-quest` **文件夹**
3. 把整个文件夹**拖进**网页中间那个虚线框里（不是拖单个文件，拖文件夹）
4. 等 10～30 秒，页面顶部会出现一个网址，像 `https://silly-cat-123456.netlify.app`
5. **这时先别关页面**。点页面上的 `Sign up` / `Claim your site`，用邮箱或 GitHub 免费注册一个账号
   （⚠️ 不注册的话，这个网址过一段时间就会被删除）
6. 登录后进入站点设置，可以改名：`Site configuration` → `Change site name` → 改成 `life-quest-你的名字`，
   网址就变成 `https://life-quest-你的名字.netlify.app` 这样好记的
7. 把网址记下来（发到微信"文件传输助手"最方便）

### 方案 B：GitHub Pages（永久免费、更稳，多花 5 分钟）

1. 打开 <https://github.com> 注册一个账号（免费的）
2. 右上角 `+` → `New repository`
3. `Repository name` 填 `life-quest`，选 **Public**，点 `Create repository`
4. 在新页面点 `uploading an existing file`（蓝色链接）
5. 把 `life-quest` 文件夹里的**全部内容**拖进去：
   `index.html`、`styles.css`、`app.js`、`manifest.json`、`sw.js`、`icons` 文件夹
   ⚠️ 一定要让 `index.html` 出现在**最外层**，不能是 `life-quest/index.html`
6. 点下面的绿色 `Commit changes`
7. 点仓库上方的 `Settings` → 左边 `Pages`
8. `Source` 选 `Deploy from a branch`；`Branch` 选 `main`、文件夹选 `/ (root)` → 点 `Save`
9. 等 1～2 分钟，刷新这个页面，顶部会出现：
   `Your site is live at https://你的用户名.github.io/life-quest/`
10. 这个网址就是你的应用地址，永久免费

> **国内网络提示**：GitHub Pages 和 Netlify 在国内访问速度不稳定，第一次可能要多刷几次。
> 如果实在打不开，把网址发到手机上用 4G/5G 再试，通常能开。

### 验证一下

在**电脑浏览器**里打开你拿到的网址，能看到应用 = 上传成功。看不到就回到第 5 步检查文件层级。

## 第 4 步 · 在 iPhone 上"安装"（30 秒）

1. **必须用 Safari**（iPhone 上的 Chrome 不能添加到主屏幕）
2. 地址栏输入你刚才的网址，打开
3. 点屏幕**底部中间的分享按钮**（一个方框往上箭头 ⬆️）
4. 在列表里往下找，点 **「添加到主屏幕」**
5. 名字可以改成「人生副本」，点右上角 **「添加」**
6. 回到桌面，就有一个金色星星图标的 App 了

打开它试试：

- 应该是**全屏、没有地址栏**的
- 开关飞行模式，再打开它 —— **照样能用**（这就是 `sw.js` 的功劳）

> 就这样，你已经有"一个装在自己手机上的 App"了。而且完全免费、不用上架。

## 第 5 步 · 把它配置成"你自己的"（最重要的一步，别跳过）

默认那几个任务是示例，**全部改成你自己的**，否则你三天就会弃用。

进「任务」页，把不合适的点「改」→ 删掉，然后建你自己的。建议结构：

- **每日任务 3～5 个**（超过 6 个必弃）；每个用时 10 分钟～1 小时
- **每周任务 2～3 个**（周内做完就行，不用每天）
- **BOSS 任务 1 个**（一件拖了很久、有明确截止日期的大事）

### 关键原则：任务要"小到你不好意思不做"

| ❌ 别这样写 | ✅ 这样写 |
|---|---|
| 学英语 | 背 20 个单词 |
| 健身 | 做 20 个俯卧撑 |
| 读完一本书 | 读 10 页 |
| 减肥 | 今天不喝奶茶 |

### 两套可以直接照抄的配置

**A. 学生 / 备考型**

| 类型 | 任务 | 目标 | 难度 |
|---|---|---|---|
| 每日 | 早起（7:30 前） | 1 次 | 轻松 |
| 每日 | 背单词 | 30 个 | 普通 |
| 每日 | 专注学习 | 2 小时 | 困难 |
| 每日 | 运动 | 20 分钟 | 普通 |
| 每周 | 做完一套真题 | 2 套 | 困难 |
| 每周 | 整理错题本 | 1 次 | 普通 |
| BOSS | 考过 XX 考试 | 1 个 | 史诗（截止日期填考试前一天） |

**B. 上班族型**

| 类型 | 任务 | 目标 | 难度 |
|---|---|---|---|
| 每日 | 8:30 前起床 | 1 次 | 轻松 |
| 每日 | 喝够 8 杯水 | 8 杯 | 轻松 |
| 每日 | 深度工作 | 3 小时 | 困难 |
| 每日 | 运动 / 散步 | 1 次 | 普通 |
| 每周 | 健身房 3 次 | 3 次 | 困难 |
| 每周 | 周复盘（下周计划） | 1 次 | 普通 |
| BOSS | 完成 XX 项目 | 1 个 | 史诗（带截止日） |

### 奖励怎么定价

奖励 = 你真的会想要的、平时会愧疚的小事。定价参考：

- 打卡一天大概赚 **30～50 金币**（普通难度几个任务）
- 所以「一杯奶茶 60 金币」≈ 认真打 1.5 天卡
- 「玩游戏 1 小时 80」≈ 2 天
- 「买一件想了很久的东西 800」≈ 3 周

**定价太低 → 没有挑战感；太高 → 永远兑不了，会放弃。**

## 第 6 步 · 第一次改代码（5 分钟，很有成就感）

用**记事本**就能改（推荐装免费的 [VS Code](https://code.visualstudio.com/)，中文界面、能高亮颜色）。

> ⚠️ 动手前：把整个 `life-quest` 文件夹**复制一份**当备份。改坏了就用备份。

### 练习 1：换个主题色（改 1 行）

1. 右键 `styles.css` → 打开方式 → 记事本
2. 找到最上面 `:root{` 里面这一行：
   ```css
   --accent:    #4fd1c5;   /* 主色（青） */
   ```
3. 把 `#4fd1c5` 改成别的颜色代码，比如 `#ff8fa3`（粉）、`#8b9dff`（蓝紫）
4. 保存，刷新浏览器 → 按钮、进度条全变色了

### 练习 2：让升级更快 / 更慢（改 2 个数字）

打开 `app.js`，搜索 `XP_BASE`：

```js
const XP_BASE = 100, XP_STEP = 40;
```

- `XP_BASE = 100` 表示 **1 级升 2 级需要 100 经验**
- `XP_STEP = 40` 表示之后每级多要 40

改成 `XP_BASE = 60` 就是升级飞快（适合刚开始没耐心的时候），改成 `200` 就是慢熬型。

### 练习 3：改应用名字（改 3 处，要一致）

1. `index.html` 第 13 行：`<title>人生副本 · Life Quest</title>`
2. `index.html` 第 11 行：`<meta name="apple-mobile-web-app-title" content="人生副本">`（这是加到桌面时的名字）
3. `manifest.json` 里 `"name"` 和 `"short_name"`

### 练习 4：加一个自定义成就

打开 `app.js`，搜 `ACHIEVEMENTS`，在数组里加一行：

```js
{ id: 'my-early', icon: '🌄', name: '早起达人', desc: '累计完成 20 次早起', test: (s) => s.totalDone >= 20 },
```

`test` 是一个判断函数，返回 `true` 就点亮。`s` 里可用的数据：`s.totalDone`（累计完成次数）、
`s.streak`（当前连续）、`s.bestStreak`（最长连续）、`s.level`、`s.bossDone`、`s.coinsEarned`、`s.perfectDays`。

**改完记得把 `sw.js` 第一行的版本号 +1**（现在文件里是 `lifequest-v4`，改成 `v5`），否则手机可能还在用旧缓存。

## 第 7 步 · 数据安全（请认真看）

| 情况 | 数据会怎样 |
|---|---|
| 用同一个手机、同一个网址打开 | 数据都在 ✅ |
| 手机里"清除 Safari 数据" | **全没了** ❌ |
| 换手机 / 换电脑 | 不会自动同步 ❌ |
| 换个浏览器（Safari→Chrome） | 各自独立，数据不共享 ❌ |
| iPhone 上装了桌面图标，但 7 天没打开 | 装到桌面后不会被系统清理 ✅ |

**所以：每周点一次「我的」→「导出备份」。** 换手机时在新手机上「导入备份」，数据就回来了。

> 备份文件是一个 `.json`，里面是你所有任务、记录、金币。不要发给别人也无所谓，都是你自己的数据。
> iPhone 上导出后会存到「文件」App 的「下载」里，可以再传到 iCloud 或电脑。

## 第 8 步 · 以后怎么更新版本（重点，你在 GitHub Pages 上）

先分清两件事，很多人在这里白折腾：

| 你想改的东西 | 要不要动代码/上传 | 手机怎么生效 |
|---|---|---|
| 任务、奖励、名字、头像 | ❌ 不用 | 打开应用直接改，立刻生效（数据存在手机里） |
| 颜色、功能、界面、数值（`app.js`/`styles.css`/`index.html`） | ✅ 要重新上传 | 按下面 4 步 |

### 一、在本机改好并自测

1. 双击 `index.html`，在电脑浏览器里试，确认新功能没问题（改坏了先别上传）
2. **把 `sw.js` 第 1 行的版本号 +1**：文件里现在是 `lifequest-v4`，改成 `lifequest-v5`
   （这一步经常忘，忘了手机可能还在用旧代码）
3. 顺手把 `app.js` 里「关于」那段显示的 `v3.1` 改成 `v3.2`
   （这是你之后用来确认"手机上到底更新成功没有"的标记）

### 二、上传到 GitHub（浏览器操作，不用装任何软件）

1. 打开 <https://github.com> → 登录 → 点进你的 `life-quest` 仓库
2. 点右侧的 **`Add file`** → **`Upload files`**
3. 把改过的文件**拖进去**（拖进页面中间的大方框）
   - 拖 `app.js` 这种单个文件 → 会自动覆盖同名旧文件
   - 也可以把整个文件夹拖进来，但**一定要确认传到仓库根目录**，不要变成 `life-quest/life-quest/app.js`
   - 页面下方会显示 `2 files changed` 之类的提示，说明覆盖生效
4. 在下面 `Commit changes` 的框里写一句备注（例：`加专注计时`），点绿色 **`Commit changes`**

### 三、等部署完成（约 30 秒～2 分钟）

怎么知道好了：

- 点仓库上方的 **`Actions`** 标签 → 有一条记录在跑 → 出现**绿色对勾**就是部署完成
- 或 `Settings` → `Pages`，顶部会写 `Your site was last deployed ...`

### 四、手机上看到新版

1. **彻底关掉**桌面上的「人生副本」（从屏幕底部上滑 → 把这页卡片向上滑掉）
2. 重新点开
3. 它会自动提示「发现新版本，正在更新…」并刷新一次（这个机制我已经写进代码了）
4. 去「我的」→ 拉到底，看版本号是不是 `v3.2`。是 → 成功

**还是旧版怎么办？按顺序试：**

| 现象 | 原因 | 解决 |
|---|---|---|
| 等了一会儿还是旧的 | GitHub 的 CDN 有缓存 | 再等 2～5 分钟，重新开关一次应用 |
| 一直不更新 | `sw.js` 版本号没改 | 改版本号，重新上传 |
| 白屏 / 打不开 | 代码写错了 | 见下面的「回滚」 |
| 只有部分变了 | 只上传了部分文件 | 确认 `app.js`、`styles.css`、`index.html`、`sw.js` 都是最新的 |

**强行刷新（最后手段，不会丢数据）：**
在 iPhone 的 **Safari**（不是桌面图标）里打开同一个网址 → 下拉刷新 → 再回桌面图标打开。
⚠️ 不要用「设置 → Safari → 清除历史记录与网站数据」，那会**清空你的打卡数据**！

### 改坏了怎么回滚（这个一定要会）

GitHub 帮你记着每一次修改：

1. 仓库里点开那个被改坏的文件 → 右上角 **`History`**（或时钟图标）
2. 找到上一个正常的版本，点进去
3. 点右上角 `...` → `View file` → 复制全部内容
4. 回到最新版 → 点铅笔图标 ✏️ → 全选删除 → 粘贴旧内容 → `Commit changes`

或者更稳的做法：**每次改代码前，把整个 `life-quest` 文件夹复制一份**
（`life-quest-备份-1031`），改坏了直接把备份里那几个文件重新拖上去。

### 更新流程速记

```
改文件 → sw.js 版本号 +1 → 电脑双击 index.html 自测
  → GitHub: Add file → Upload files → 拖进去 → Commit
  → 等 Actions 出绿勾
  → 手机上彻底关掉应用再打开 → 「我的」看版本号
```

## 常见问题

**Q：为什么点打卡没有反应？**
A：任务显示「已完成」时按钮是灰的，要先点「撤销」。另外每日任务会在**第二天自动重置**，每周任务在**周一凌晨**重置。

**Q：我改了代码，手机上还是老样子？**
A：完整流程见 **第 8 步**。90% 的情况是这两个原因：① `sw.js` 的版本号没 +1；② 没有把应用彻底关掉重开。先等 2 分钟（GitHub 有缓存），再按第 8 步的四步走一遍。

**Q：能给我加个每天 21:00 提醒吗？**
A：网页应用**做不到**（这是 iOS 的限制，不是代码问题）。变通方案：手机自带「提醒事项」设一个每天 21:00 的提醒，内容写"打开人生副本打卡"。

**Q：两个手机能同步吗？**
A：现在不能。要么手动导出/导入，要么加后端（第 9 步），要么把数据放一个共享网盘（麻烦）。

**Q：会花钱吗？**
A：不会。托管免费额度对个人用绰绰有余，代码全在你自己电脑里。

**Q：白屏 / 打不开怎么办？**
A：① 确认 `index.html` 在网址根目录（打开网址应该直接是应用）；② 电脑上按 F12 打开控制台看红色报错；③ 把我给你的文件夹重新拖一次；④ 改坏了就用第 8 步的「回滚」。

**Q：我能删掉 `preview` 和 `tools` 文件夹吗？**
A：能，它们不影响运行。`preview` 是截图，`tools` 是生成图标的脚本。

**Q：默认任务的数值太简单/太难？**
A：去「我的」→「追加演示任务」看看别的写法；或者按第 6 步练习 2 调升级速度。
