# 人生副本 · Life Quest

一个把日常工作学习变成 RPG 的小应用：**每日 / 每周 / BOSS 任务 → 打卡 → 升级 + 金币 → 兑换真实奖励 → 成长记录**。

- 一套代码，**iPhone 和 Windows 电脑都能用**
- 纯前端，**不需要服务器、不需要账号、不需要开发者证书**
- 数据存在你自己的设备里，不上传任何地方
- 免费

---

## 一、先用起来（Windows，1 分钟）

双击 `index.html`，用 Edge 或 Chrome 打开就能用。

想固定入口：浏览器右上角 `⋯` → 收藏夹 → 收藏，或者把 `index.html` 发送快捷方式到桌面。

> 手机上必须先把这 6 个文件传到网上（免费），再用 Safari「添加到主屏幕」。
> 详细步骤看 **《手把手教程.md》**。

## 二、项目里每个文件是干什么的

| 文件 | 作用 | 需要改吗 |
|---|---|---|
| `index.html` | 页面骨架（顶部状态栏、四个标签页、底部导航） | 一般不用 |
| `styles.css` | 全部外观：颜色、圆角、字号、动画都在这里 | 想换配色时改第 8~20 行 |
| `app.js` | 全部逻辑：任务、经验、金币、成就、备份 | 想加功能时改 |
| `manifest.json` | 应用名、图标、"安装到桌面"时显示的样式 | 改名时改 |
| `sw.js` | 离线缓存，让应用断网也能打开 | 不用 |
| `icons/` | 应用图标（由 `tools/make_icons.py` 生成） | 想换图标时重跑脚本 |
| `preview/` | 效果截图，可以删 | — |

## 三、想改什么，改哪里

| 我想…… | 怎么做 | 位置 |
|---|---|---|
| 换任务 / 改任务 / 删任务 | **直接点界面**，不用改代码 | 任务页「＋ 新建」，卡片上的「改」 |
| 换奖励 | 直接点界面 | 奖励页「＋ 上架」 |
| 加减惩罚事件 | 直接点界面 | 奖励页 → 惩罚 → 「＋ 新建惩罚项」 |
| 改娱乐时长的兑换比例 | 直接点界面 | 我的 → 数值设置 → 娱乐时长兑换比例 |
| 改「完成几个任务送多少分钟」 | 直接点界面 | 我的 → 数值设置 → 每日达标奖励 |
| 换名字、头像 | 直接点界面 | 「我的」页 |
| **给某个任务单独设经验/金币** | 新建或编辑时直接填数字 | 任务弹窗「经验奖励 / 金币奖励」 |
| 改经验曲线（升级快慢） | 改两个数字 | `app.js` 里 `XP_BASE = 100`、`XP_STEP = 40` |
| 改奖励倍率（每周 / BOSS 更值钱） | 改 `TYPE_MUL` | `app.js` 里 `{ daily: 1, weekly: 2, boss: 5 }` |
| 改连击加成力度 | 改 `STREAK_TIERS` | `app.js` 里 `{ min: 7, mul: 1.5 }` 这类 |
| 改专注奖励标准 | **界面里改**（不用动代码） | 专注页的输入框 / 我的 → 数值设置 |
| 改称号名称/等级 | 改 `TITLES` | `app.js` |
| 改界面配色 | 改 CSS 变量 | `styles.css` 顶部 `:root` 那一段 |
| 改应用名 | 改 3 处 | `index.html` 的 `<title>`、`manifest.json` 的 `name`、`short_name` |
| 改图标 | 改 `tools/make_icons.py` 里的颜色和形状，然后运行它 | 需要 Python + Pillow |
| 加成就 | 往数组里加一条（`coin` 是解锁送的金币） | `app.js` 的 `ACHIEVEMENTS` |
| 改默认任务/默认惩罚（给别人用） | 改 `defaultState()` | `app.js` |

改完保存，刷新浏览器就生效。**改坏了不要紧**：先复制一份备份再动手。

## 二·五、三个"钱"和六个系统（v3）

| 东西 | 怎么获得 | 怎么花 | 会不会清零 |
|---|---|---|---|
| ⚡ 经验 XP | 打卡、专注、连击加成 | 只用于升级（不会被花掉） | 不清零 |
| 🪙 金币 | 打卡、专注、升级、成就 | 兑换奖励 / 兑换娱乐时长 | 不清零 |
| ⏳ 娱乐时长 | **用金币兑换**（比例可自定义，默认 2 金币换 1 分钟）、每日达标送 60 分钟 | **用掉**（看剧/游戏前先扣） | 不清零，累积 |

- **惩罚**：破戒点「记一次」，扣经验扣金币，同时进流水和「最近被罚」
- **日记**：每天一条，自动带当天收支汇总（金币支出分成 奖励 / 惩罚 / 兑换时长 三类）
- **流水**：经验、金币、时长的每一笔增减，可按类型筛选（老存档会自动补一份）
- **备忘**：记事 + 提醒时间；到点弹提醒（**只在应用打开时**，iOS 关掉后不会响）

## 三·五、改了代码怎么更新到手机

1. 本机双击 `index.html` 自测
2. **`sw.js` 第 1 行版本号 +1**（现在是 `lifequest-v4`，改成 `v5`）
3. GitHub 仓库 → `Add file` → `Upload files` → 拖进去覆盖 → `Commit changes`
4. `Actions` 出现绿勾 = 部署完成
5. 手机上彻底关掉应用再重开（会自动提示"发现新版本，正在更新…"）
6. 「我的」页拉到底看版本号确认

**详细图文步骤、失败排查、回滚方法见《手把手教程.md》第 8 步。**

## 四、数据在哪 / 怎么不丢

- 数据存在浏览器的 `localStorage`（键名 `lifequest.v1`）。
- 换设备、清缓存、换浏览器 → 数据不会跟过去。
- **定期备份**：「我的」→「导出备份」，会下载一个 `.json` 文件。
- 恢复：同一位置「导入备份」。
- iPhone 上建议务必「添加到主屏幕」：装到桌面的应用不会因为 7 天没用而被系统清掉数据。

## 五、玩法数值（默认）

- 升级：1→2 级需要 100 经验，之后每级 +40（2→3 级 140，3→4 级 180……）
- 任务奖励 = 难度基础值 × 类型倍率
  - 难度：轻松 15XP/4金币，普通 30/8，困难 60/18，史诗 120/40
  - 类型：每日 ×1，每周 ×2，BOSS ×5
  - （新建任务时可以直接改这两个数字，改完以你填的为准）
- **连击加成**：连续第 3 天 ×1.2，第 7 天 ×1.5，第 14 天 ×1.8，第 30 天 ×2.0，断一天归零
- **专注奖励**：默认每分钟 1.5 XP + 0.35 金币（可在界面上改），再乘连击倍率
- **成就奖励**：解锁即送 50～800 金币
- **等级称号**：1 新手学徒 / 3 冒险者 / 6 见习勇者 / 10 勇者 / 15 精英猎人 / 20 英雄 / 30 传说 / 50 神话
- **娱乐时长**：默认 **2 金币换 1 分钟**（比例可改成「几金币换几分钟」）；每天完成 5 个任务额外送 60 分钟；
  用不完会累积，看剧/打游戏前在同一个卡片里点「用掉」扣掉（都能在「我的 → 数值设置」改）
- 升级额外奖励金币：`20 + 等级×5`
- 连续天数：从今天（或昨天）往前数，打卡或专注都算一天

以上都是**默认值**，除了经验曲线，其余都能在「我的 → 数值设置」或对应页面直接改，改完立刻生效。
